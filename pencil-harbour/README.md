# 铅笔港湾 Pencil Harbour

彩色铅笔画风的 3D 小游戏，纯代码生成（Three.js r160），没有任何外部模型或贴图文件。

## 玩法

- WASD / 方向键：移动，Shift 奔跑，空格跳
- 拖动鼠标看四周，滚轮缩放
- 在小镇里找到 8 支彩色铅笔，全部收集后迎来日落结局

## 内容

- 程序生成的意大利海港小镇：房屋、码头、灯塔、喷泉、集市、小船
- 彩铅后期着色、SSAO、日落光照、窗户和路灯发光
- 会走动的镇民、钓鱼的人、猫、鸽子、蝴蝶
- 主角：穿黄雨衣的 Q 版小画家，背包里会显示收集到的铅笔

## 调试小功能

- `#demo`：自动演示，沿铅笔路线跑一遍
- `#play=x,z,yaw,pitch,dist`：从指定位置开始
